# Optional idle-tab cleanup

Agents can leave tabs open after their work is done.
The separate, optional project [cdpidletabs](https://github.com/TayHCode/cdpidletabs) closes tabs that have not changed
for a configured time.
It accepts the same HTTP endpoint this tool prints.
It is not part of cdp-setup-kit.
This tool does not install, schedule or run it.
This tool installs no timer of any kind.
Unlike this tool, the companion lists tabs by design.
Read its README before choosing to use it.
