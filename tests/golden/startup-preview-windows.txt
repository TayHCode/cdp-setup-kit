Would then run this command:
  schtasks /Query /TN cdp-setup-kit-work /XML
Would then run this command:
  schtasks /Create /TN cdp-setup-kit-work /XML D:\kit-data\state\startup\cdp-setup-kit-work.xml
For an existing marked entry that differs, use this command instead:
  schtasks /Create /TN cdp-setup-kit-work /XML D:\kit-data\state\startup\cdp-setup-kit-work.xml /F
Effect: the "work" Chrome window opens each time you sign in.
To do it:   cdp-setup-kit startup enable work --apply
To undo it: cdp-setup-kit startup disable work --apply
